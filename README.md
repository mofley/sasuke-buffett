# Sasuke Buffett V1

GitHub Pages-ready PWA package.

## Deploy
1. Create a GitHub repo named `sasuke-buffett`.
2. Upload all files in this folder to the repo root.
3. Go to Settings → Pages.
4. Source: Deploy from branch → `main` → `/root`.
5. Open the published `https://YOURUSERNAME.github.io/sasuke-buffett/` link in iPhone Safari.
6. Tap Share → Add to Home Screen.

## Notes
- Journal data saves locally in the browser using IndexedDB.
- Export downloads a CSV file.
- The optional OpenAI key field is for local testing only. Client-side API keys are not secure for production.
